Aide et questions fréquentes
  • Où acheter un code ? Chez un revendeur à Kitutu, en espèces (FC).
  • Combien de temps ? Votre forfait est illimité pendant toute sa durée : pas de compteur de données.
  • Le temps commence quand ? À la première utilisation du code, pas à l'achat.
  • J'ai perdu ma connexion ? Réentrez le même code : il reprend le temps restant.
  • Le code ne passe pas ? Vérifiez les caractères : il n'y a jamais de 0, O, 1, I ni l.
  • Un code pour deux personnes ? Non : un code ne peut pas servir deux fois en même temps.
